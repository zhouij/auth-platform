# Auth Gateway + Resource Server Implementation Plan (v2)

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Build a Kotlin Spring Boot monorepo with three modules: an OAuth2 Authorization Server, an API Gateway with JWT validation, and a sample Resource Server that demonstrates authority checking and access control. Deployable via Docker Compose.

**Architecture:** Three independently deployable Spring Boot apps in a single Gradle multi-project repo. docker-compose spins them all up. The gateway sits between clients and the resource server: it validates JWT tokens and forwards requests with claim headers. The resource server trusts the gateway (via IP or forwarded headers) and implements fine-grained authorization with `@PreAuthorize`, role checks, and scope validation.

```
[Client]
    |
    v
[Auth Server :8081]  -- OAuth2 token issuance (login, grant, refresh, OIDC)
    |
    | Bearer tokens distributed to clients
    v
[Gateway :8080]      -- Reverse proxy + JWT validation + route forwarding
    |
    | Forwards only authenticated requests
    v
[Resource Server :8082] -- Domain service with role/scope-based access control
```

**Tech Stack:**
- Kotlin 1.9+ / Spring Boot 3.2+
- Auth Server: Spring MVC (servlet stack) + Spring Security OAuth2 Authorization Server 1.x
- Gateway: Spring Cloud Gateway + WebFlux (reactive stack)
- Resource Server: Spring MVC + Spring Security Resource Server (JWT validation)
- Gradle multi-project build
- Docker + docker-compose
- H2 for development, PostgreSQL configurable for production

// auth-server/src/main/kotlin/com/authserver/config/AuthorizationServerConfig.kt
package com.authserver.config

import org.springframework.context.ConfigurableApplicationContext
import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration
import org.springframework.core.annotation.Order
import org.springframework.security.config.annotation.web.builders.HttpSecurity
import org.springframework.security.config.annotation.web.configurers.oauth2.server.resource.OAuth2ResourceServerConfigurer
import org.springframework.security.oauth2.core.AuthorizationGrantType
import org.springframework.security.oauth2.core.ClientAuthenticationMethod
import org.springframework.security.oauth2.server.authorization.client.InMemoryRegisteredClientRepository
import org.springframework.security.oauth2.server.authorization.client.RegisteredClient
import org.springframework.security.oauth2.server.authorization.config.annotation.web.configuration.OAuth2AuthorizationServerConfiguration
import org.springframework.security.oauth2.server.authorization.config.annotation.web.configurers.OAuth2AuthorizationServerConfigurer
import org.springframework.security.oauth2.server.authorization.settings.AuthorizationServerSettings
import org.springframework.security.oauth2.server.authorization.settings.ClientSettings
import org.springframework.security.oauth2.server.authorization.settings.TokenSettings
import org.springframework.security.oauth2.server.authorization.token.JwtEncodingContext
import org.springframework.security.oauth2.server.authorization.token.OAuth2TokenCustomizer
import org.springframework.security.web.SecurityFilterChain

import java.time.Duration
import java.util.UUID

@Configuration
class AuthorizationServerConfig {

    @Bean
    @Order(1)
    fun authorizationServerSecurityFilterChain(
        http: HttpSecurity,
        context: ConfigurableApplicationContext
    ): SecurityFilterChain {
        OAuth2AuthorizationServerConfiguration.applyDefaultSecurity(http)

        http.getConfigurer<OAuth2AuthorizationServerConfigurer>()
            .oidc { oidc -> oidc }

        return http.build()
    }

    @Bean
    fun registeredClientRepository(): InMemoryRegisteredClientRepository {
        val webClient = RegisteredClient.builder(UUID.randomUUID().toString())
            .clientId("web-client")
            .clientSecret("{noop}secret")
            .clientAuthenticationMethod(ClientAuthenticationMethod.CLIENT_SECRET_BASIC)
            .authorizationGrantType(AuthorizationGrantType.AUTHORIZATION_CODE)
            .authorizationGrantType(AuthorizationGrantType.REFRESH_TOKEN)
            .scope("openid")
            .scope("read")
            .scope("write")
            .redirectUri("http://localhost:3000/callback")
            .redirectUri("http://localhost:8081/callback")
            .postLogoutRedirectUri("http://localhost:3000/")
            .tokenSettings(TokenSettings.builder()
                .accessTokenTimeToLive(Duration.ofHours(1))
                .refreshTokenTimeToLive(Duration.ofDays(1))
                .reuseRefreshTokens(false)
                .build())
            .clientSettings(ClientSettings.builder()
                .requireAuthorizationConsent(true)
                .build())
            .build()

        val serviceClient = RegisteredClient.builder(UUID.randomUUID().toString())
            .clientId("service-client")
            .clientSecret("{noop}service-secret")
            .clientAuthenticationMethod(ClientAuthenticationMethod.CLIENT_SECRET_BASIC)
            .authorizationGrantType(AuthorizationGrantType.CLIENT_CREDENTIALS)
            .scope("read")
            .scope("write")
            .tokenSettings(TokenSettings.builder()
                .accessTokenTimeToLive(Duration.ofHours(2))
                .build())
            .build()

        return InMemoryRegisteredClientRepository(webClient, serviceClient)
    }

    @Bean
    fun authorizationServerSettings(): AuthorizationServerSettings {
        return AuthorizationServerSettings.builder()
            .issuer("http://localhost:8081")
            .build()
    }

    @Bean
    fun tokenCustomizer(): OAuth2TokenCustomizer<JwtEncodingContext> {
        return OAuth2TokenCustomizer { context ->
            if (context.authorization != null) {
                context.jacksonObject
                    .setProperty("clientId", context.clientRegistration.clientId)
                    .setProperty("custom", "auth-server-value")
            }
        }
    }
}
```

package com.authserver.config

import org.springframework.context.annotation.Bean
import org.springframework.context.annotation.Configuration
import org.springframework.core.annotation.Order
import org.springframework.security.config.annotation.web.builders.HttpSecurity
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity
import org.springframework.security.config.http.SessionCreationPolicy
import org.springframework.security.web.SecurityFilterChain

@Configuration
@EnableWebSecurity
class SecurityConfig {

    @Bean
    @Order(2)
    fun defaultSecurityFilterChain(http: HttpSecurity): SecurityFilterChain {
        http
            .authorizeHttpRequests { authorize ->
                authorize
                    .requestMatchers("/h2-console/**").permitAll()
                    .requestMatchers("/actuator/**").permitAll()
                    .anyRequest().authenticated()
            }
            .sessionManagement { it.sessionCreationPolicy = SessionCreationPolicy.STATELESS }
            .httpBasic { }
            .oauth2ResourceServer { resourceServer ->
                resourceServer.jwt { }
            }
            .headers { headers ->
                headers.frameOptions { frames -> frames.disable() }
            }
            .csrf { it.disable() }

        return http.build()
    }
}

### Task 5: Global JWT Auth Filter

**Objective:** Add a global filter that extracts JWT claims and forwards them as headers to downstream services.

**Files:**
- Create: `gateway/src/main/kotlin/com/authgateway/filter/GlobalAuthFilter.kt`

**Step 1: GlobalAuthFilter**

```kotlin
// gateway/src/main/kotlin/com/authgateway/filter/GlobalAuthFilter.kt
package com.authgateway.filter

import org.springframework.cloud.gateway.filter.GatewayFilterChain
import org.springframework.cloud.gateway.filter.GlobalFilter
import org.springframework.core.Ordered
import org.springframework.http.HttpHeaders
import org.springframework.http.HttpStatus
import org.springframework.security.oauth2.server.resource.authentication.BearerTokenAuthentication
import org.springframework.stereotype.Component
import org.springframework.web.server.ServerWebExchange
import reactor.core.publisher.Mono
import reactor.kotlin.core.publisher.then

@Component
class GlobalAuthFilter : GlobalFilter, Ordered {

    override fun filter(
        exchange: ServerWebExchange,
        chain: GatewayFilterChain
    ): Mono<Void> {
        val path = exchange.request.uri.path

        // Let actuator paths pass without auth
        if (path.startsWith("/actuator/")) {
            return chain.filter(exchange)
        }

        // Check if there's already an authenticated principal (set by Spring Security)
        val auth = exchange.principal
            .as(Brace { it.cast(BearerTokenAuthentication::class.java) })

        return auth.switchIfEmpty(
            // No auth principal found - reject
            Mono.defer {
                exchange.response.statusCode = HttpStatus.UNAUTHORIZED
                exchange.response.setComplete()
            }
        ).flatMap { bearerAuth ->
            val jwt = bearerAuth.token

            // Forward JWT claims as headers for downstream services
            val newHeaders = HttpHeaders()
            newHeaders[HttpHeaders.AUTHORIZATION] = listOf("Bearer ${jwt.rawToken}")
            newHeaders["X-User-Id"] = listOf(jwt.subject)
            newHeaders["X-User-Scope"] = jwt.scopes?.joinToString(",") ?: "none"
            newHeaders["X-Client-Id"] = jwt.claims["clientId"]?.toString() ?: "unknown"

            val mutatedExchange = exchange.mutate()
                .request { req ->
                    req.headers(newHeaders)
                }
                .build()

            chain.filter(mutatedExchange)
        }.onErrorResume(Exception::class.java) {
            exchange.response.statusCode = HttpStatus.UNAUTHORIZED
            exchange.response.setComplete()
        }
    }

```kotlin
// resource-server/src/main/kotlin/com/resourceserver/config/CompositeJwtGrantedAuthoritiesConverter.kt
package com.resourceserver.config

import org.springframework.security.core.GrantedAuthority
import org.springframework.security.core.authority.SimpleGrantedAuthority
import org.springframework.security.oauth2.core.OAuth2Error
import org.springframework.security.oauth2.core.OAuth2ErrorCodes
import org.springframework.security.oauth2.server.resource.authentication.JwtAuthenticationConverter
import org.springframework.security.oauth2.server.resource.authentication.JwtGrantedAuthoritiesConverter
import org.springframework.security.oauth2.jwt.Jwt

/**
 * Combines Spring Security ROLE_ authorities (from JWT "roles" claim) with
 * OAuth2 SCOPE_ authorities (from JWT "scope" claim). This allows using both
 * @PreAuthorize("hasRole('ADMIN')") and @PreAuthorize("#oauth2.hasScope('write')")
 */
class CompositeJwtGrantedAuthoritiesConverter : JwtGrantedAuthoritiesConverter() {

    override fun convert(jwt: Jwt): Collection<GrantedAuthority> {
        val authorities = mutableSetOf<GrantedAuthority>()

        // Standard OAuth2 scopes -> SCOPE_read, SCOPE_write
        val scopes = jwt.convertToScopes()
        authorities.addAll(scopes.map {
            SimpleGrantedAuthority("SCOPE_$it")
        })

        // Custom "roles" claim from our token customizer -> ROLE_ADMIN, ROLE_USER
        jwt.claims["roles"]?.let {
            @Suppress("UNCHECKED_CAST")
            val roles = it as List<String>
            authorities.addAll(roles.map { role ->
                SimpleGrantedAuthority("ROLE_$role")
            })
        }

        // Also pick up "scope" claim as a list if present
        jwt.claims["scope"]?.let {
            @Suppress("UNCHECKED_CAST")
            val scopeFromClaim = it as List<String>
            authorities.addAll(scopeFromClaim.map { s ->
                SimpleGrantedAuthority("SCOPE_$s")
            })
        }

        // Add the standard OAuth2User authority
        authorities.add(JwtAuthenticationConverter.DEFAULT_AUTHORITY)

        return authorities
    }

    private fun Jwt.convertToScopes(): MutableSet<String> {
        val scopes = mutableSetOf<String>()
        claims["scope"]?.let {
            @Suppress("UNCHECKED_CAST")
            (it as List<String>).forEach(scopes::add)
        }
        return scopes
    }
}

package com.resourceserver.service

import org.springframework.stereotype.Service

/**
 * Demonstrates domain-level authorization checks.
 * A resource owner can read/write their own resources regardless of role.
 * Other users need appropriate roles/scopes.
 */
@Service
class AuthorizationChecker {

    /**
     * Check if the requesting user can read a resource.
     * Permission granted if: the user is the resource owner OR has ADMIN role OR has USER role.
     */
    fun canRead(requesterId: String, ownerId: String, role: String?): Boolean =
        isOwner(requesterId, ownerId) || isAdmin(role) || isUser(role)

    /**
     * Check if the requesting user can write a resource.
     * Permission granted if: the user is the resource owner OR has ADMIN role.
     */
    fun canWrite(requesterId: String, ownerId: String, role: String?): Boolean =
        isOwner(requesterId, ownerId) || isAdmin(role)

    /**
     * Check if the requesting user can delete a resource.
     * Permission granted if: the user is the resource owner OR has ADMIN role.
     */
    fun canDelete(requesterId: String, ownerId: String, role: String?): Boolean =
        isOwner(requesterId, ownerId) || isAdmin(role)

    private fun isOwner(requesterId: String, ownerId: String): Boolean =
        requesterId == ownerId

    private fun isAdmin(role: String?): Boolean =
        role?.uppercase() == "ADMIN"

    private fun isUser(role: String?): Boolean =
        role?.uppercase() in setOf("USER", "ADMIN")
}

### Prerequisites
- JDK 17+
- Docker + Docker Compose (optional)

### Run Locally

```bash
# Terminal 1 - Auth Server
cd auth-server && ../gradlew bootRun

# Terminal 2 - Gateway
cd gateway && ../gradlew bootRun

# Terminal 3 - Resource Server
cd resource-server && ../gradlew bootRun
```

### Run with Docker

```bash
docker-compose up --build
```

### End-to-End Flow

```bash
# 1. Get a token from the Authorization Server
TOKEN=$(curl -s -X POST http://localhost:8081/oauth2/token \
  -u "service-client:service-secret" \
  -d "grant_type=client_credentials&scope=read")

ACCESS_TOKEN=$(echo "$TOKEN" | grep -o '"access_token":"[^"]*"' | cut -d'"' -f4)

# 2. Call the Resource Server via the Gateway
curl -s -H "Authorization: Bearer $ACCESS_TOKEN" \
  http://localhost:8080/api/whoami

# 3. Access public endpoints (no auth needed)
curl -s http://localhost:8080/api/public/status

# 4. Admin endpoint (will 403 without ADMIN role)
curl -s -H "Authorization: Bearer $ACCESS_TOKEN" \
  http://localhost:8080/api/admin/users
```

## Authorization Patterns Demonstrated

The resource-server is a reference implementation showing these patterns:

### 1. Method-Level Authorization (`@PreAuthorize`)
```kotlin
@PreAuthorize("#oauth2.hasScope('write')")
fun createResource(...) // Only clients with 'write' scope

@PreAuthorize("hasRole('ADMIN')")
fun listUsers(...) // Only users with ADMIN role
```

### 2. Owner-Based Access Control
```kotlin
if (!authorizationChecker.canRead(requesterId, owner, role)) {
    // 403 Forbidden
}
```

### 3. URL-Level Path Security
```kotlin
.requestMatchers("/api/public/**").permitAll()
.anyRequest().authenticated()
```

### 4. JWT Claims as Authorities
Spring Security `ROLE_` and `SCOPE_` authorities are extracted automatically from JWT claims via the `CompositeJwtGrantedAuthoritiesConverter`.

## API Endpoints

### Auth Server (:8081)
| Endpoint | Method | Description |
|----------|--------|-------------|
| `/.well-known/openid-configuration` | GET | OIDC discovery document |
| `/oauth2/authorize` | GET/POST | Authorization code consent/login |
| `/oauth2/token` | POST | Token grant and refresh |
| `/oauth2/jwks` | GET | JWT public key (JWK set) |
| `/logout` | POST | End session |

### Resource Server (:8082) - via Gateway at /api/...
| Endpoint | Auth Required | Method | Description |
|----------|---------------|--------|-------------|
| `/api/public/status` | No | GET | Public health check |
| `/api/resources` | Yes (read scope) | GET | List all accessible resources |
| `/api/resources/{id}` | Yes (read scope) | GET | Get specific resource |
| `/api/resources` | Yes (write scope) | POST | Create resource |
| `/api/resources/{id}` | Yes (write scope) | PUT | Update resource |
| `/api/resources/{id}` | Yes (write scope) | DELETE | Delete resource |
| `/api/admin/users` | ADMIN role | GET | Admin: list all users |
| `/api/my-resources` | Yes | GET | Get resources owned by requester |
| `/api/whoami` | Yes | GET | Inspect current JWT claims |

## Extending the Resource Server

This is a reference implementation. To adapt for your domain:

1. Replace the in-memory sample data with a JPA/Hibernate entity and repository
2. Add your own domain models in `com/resourceserver/domain/`
3. Create controllers that follow the authorization patterns shown in `DemoController`
4. Add new clients to `AuthorizationServerConfig` for different OAuth2 flows
5. Configure PostgreSQL by overriding `spring.datasource.*` properties
6. Add rate limiting in the Gateway using `RequestRateLimiter` filter
7. Add the resource-server module to the Gateway's route list in `application.yml`

## Risks & Tradeoffs

1. **Servlet vs Reactive split**: Auth server and resource server use Spring MVC (servlet); gateway uses WebFlux (reactive). They are separate apps communicating over HTTP, so this is not a problem. The JWT auth filter passes tokens as headers.

2. **In-memory client store**: Uses `InMemoryRegisteredClientRepository`. For production, migrate to `JdbcRegisteredClientRepository` with PostgreSQL as the persistent store.

3. **{noop} passwords**: Default passwords use `{noop}` encoding. Replace with BCrypt or Argon2 in production.

4. **Self-signed JWK keys**: OAuth2 server generates ephemeral keys at startup. For production hot reload, provide persisted keys via a `JWKSource` bean.

5. **Gateway trusts Resource Server directly**: The gateway forwards to `http://localhost:8082`. In production, the gateway should validate that downstream services also validate tokens (defense in depth), or the gateway could forward signed claims via mTLS or internal JWT signing.

6. **No CSRF protection**: Statelessness + stateless JWT tokens means CSRF is not a concern, but if you add cookies or sessions, CSRF protection must be re-enabled.

7. **Composite authority converter**: The custom `CompositeJwtGrantedAuthoritiesConverter` reads the `roles` claim. You must ensure the auth server puts `roles` in the access token (add a `TokenCustomizer` that writes the authenticated user's roles into the JWT).
